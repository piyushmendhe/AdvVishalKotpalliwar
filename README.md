# Adv. Vishal Kotpalliwar website

One-page static site: plain HTML, CSS and JavaScript, no build step.

## Files

- `index.html` – the page
- `css/styles.css` – all styling
- `js/main.js` – mobile menu, nav highlight, disclaimer
- `assets/` – cover photo, court photo, signature logo, institution logos, site icon and the practice-area photos
- `404.html` – not-found page

## Preview locally

```bash
python3 tools/serve.py
```

Then open http://localhost:4173.
